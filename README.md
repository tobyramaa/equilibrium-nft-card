# equilibrium-nft-card
A responsive NFT preview card built with semantic HTML and CSS, focusing on responsive design and clean UI structure

#Overview
A responsive NFT preview card component that displays digital asset details in a clean and modern UI design.

**Features**
Displays NFT image, title, and description
Shows Ethereum price and time remaining
Creator information section
Responsive layout

**Technologies Used**
HTML
CSS
Flexbox

**How to Run**
Open index.html in any web browser.

**Key Learnings**
This project helped me practice building responsive layouts with Flexbox, structuring semantic HTML, creating hover effects, and improving overall UI design skills.
